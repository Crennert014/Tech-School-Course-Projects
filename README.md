## 📋 Prerequisites

To run the projects in this repository:
- Java Development Kit (JDK) 8 or higher
- JavaFX SDK (for GUI projects in Chapters 14-16)
- A Java IDE (Eclipse, IntelliJ IDEA, NetBeans, or VS Code with Java extensions)

## 🏃 How to Run

### For Console Applications:
```bash
javac <filename>.java
java <classname>
```

### For JavaFX Applications:
```bash
javac --module-path /path/to/javafx-sdk/lib --add-modules javafx.controls <filename>.java
java --module-path /path/to/javafx-sdk/lib --add-modules javafx.controls <classname>
```
